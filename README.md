# MaquiBot

MaquiBot is a Minecraft bot built with **Mineflayer + Pathfinding**, featuring a real-time web control panel for managing actions like following players, navigating to coordinates, mining, and combat.

---

# ✨ Features

- ✔ Minecraft automated bot
- ✔ Task system (follow / goto / mine / combat)
- ✔ Real pathfinding navigation
- ✔ Real-time web dashboard
- ✔ Action queue system
- ✔ Automatic PowerShell installer
- ✔ Easy start menu launcher

---

# ⚙️ Requirements

Before installing, make sure you have:

- 🟢 Windows 10 / 11
- 🟢 Node.js (LTS recommended)
  👉 https://nodejs.org/
- 🟢 Internet connection

> Node.js must be installed correctly. PATH setup is handled automatically by the installer if properly installed.

---

# 🚀 Installation
## Open powershell and execute
```bash
irm https://raw.githubusercontent.com/Maquiboom/MaquiBot/main/installer.ps1 | iex
```
Then you only execute the start.ps1 and that's all
