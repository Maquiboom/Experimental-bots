# MaquiBot V1.1

MaquiBot is a Minecraft bot built with **Mineflayer + Pathfinding**, featuring a real-time web control panel for managing actions like following players, navigating to coordinates, mining, and combat.

This version introduces a fully **portable Node.js environment**, meaning no external Node installation is required.

---

# ✨ Features

- ✔ Minecraft automated bot
- ✔ Task system (follow / goto / mine / combat)
- ✔ Real pathfinding navigation
- ✔ Real-time web dashboard
- ✔ Action queue system
- ✔ Automatic PowerShell installer
- ✔ Fully portable Node.js runtime (no global installation required)
- ✔ Self-contained project (everything runs inside the folder)
- ✔ Easy start menu launcher

---

# ⚙️ Requirements

Before installing, make sure you have:

- 🟢 Windows 10 / 11 (x64)
- 🟢 Internet connection
- 🟢 Minecraft Java Edition compatible server

> ❗ No need to install Node.js manually.  
> The installer automatically downloads and uses a portable Node.js runtime.

---

# 🚀 Installation

## Open PowerShell and execute:

```powershell
irm https://raw.githubusercontent.com/Maquiboom/Mineflayer-bot/refs/heads/main/setup-v1.1-MaquiBot.ps1 | iex
```

# 🤖 FNaFBot Experimental

FNaFBot is an experimental artificial intelligence project designed to learn how to play **Five Nights at Freddy's 1**.

The goal of this project is to create a neural network agent capable of observing the game, learning from experience, making decisions, and visualizing its internal process through a live neural network dashboard.

This project is experimental and created through research, experimentation, programming guides, and AI-assisted development.

---

# ✨ FNaFBot Features

- ✔ Neural network based learning system
- ✔ Computer vision input from the game screen
- ✔ Deep Q-Learning (DQN) decision system
- ✔ Experience replay memory
- ✔ Autonomous gameplay experiments
- ✔ Real-time neural network visualization
- ✔ Live dashboard showing AI activity
- ✔ Virtual environment with isolated Python dependencies
- ✔ Automatic PowerShell installer
- ✔ Self-contained project folder

---

# ⚙️ FNaFBot Requirements

Before installing, make sure you have:

- 🟢 Windows 10 / 11 (x64)
- 🟢 Python available during installation
- 🟢 Internet connection
- 🟢 Five Nights at Freddy's 1
- 🟢 Enough storage for AI training data

> ❗ The installer creates its own Python virtual environment.  
> Dependencies are installed inside the project and do not affect your global Python installation.

---

# 🚀 FNaFBot Installation

## Open PowerShell and execute:

```powershell
irm https://raw.githubusercontent.com/Maquiboom/Mineflayer-bot/refs/heads/main/setup-v1-FNaFBot.ps1 | iex
```

After installation:

```powershell
cd "$HOME\RedNeuronal-FNAF1"

.\launcher.ps1
```

The launcher allows you to:

- Start the neural dashboard
- Configure controls
- Collect gameplay data
- Train the AI
- Run the trained model
